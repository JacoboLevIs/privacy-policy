Nous sommes désolés de vous voir partir. Si vous avez décidé de supprimer votre compte Baby Tracker IL, vous pouvez le faire directement depuis l’application.

Votre compte d’authentification est supprimé immédiatement et les enregistrements de l’application sont retirés dans le cadre du processus de suppression.

Comment supprimer votre compte

  1. Ouvrez l’application Baby Tracker IL sur votre appareil.
  2. Accédez aux Paramètres.
  3. Faites défiler vers le bas et appuyez sur « Supprimer le compte ».
  4. Confirmez votre décision lorsque cela vous est demandé.

Important

Une fois votre compte supprimé, votre compte de connexion est retiré immédiatement. Les enregistrements de base de données des profils enfants dont vous êtes l’unique propriétaire sont supprimés pendant le processus. Les profils partagés restent disponibles pour les autres soignants et certains médias téléversés, sauvegardes ou journaux de fournisseurs peuvent subsister jusqu’à un nettoyage ultérieur. Cette action est irréversible.
